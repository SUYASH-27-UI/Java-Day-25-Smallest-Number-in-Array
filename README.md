# Java Day 25 - Smallest Number in an Array

This Java program finds the smallest number in an integer array using a `for` loop and an `if` statement.

## Example

Array:
```text
12, 45, 23, 7, 30
```

Output:
```text
Smallest number = 7
```

## Concepts Used

- Arrays
- Array indexing
- `for` loop
- `if` statement
- Comparison operator `<`
- `numbers.length`

## How It Works

The program stores multiple numbers in an array. It initially assumes that the first element is the smallest. It then compares the remaining elements and updates the `smallest` variable whenever a smaller number is found.
